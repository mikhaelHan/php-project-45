## Description
«Игры разума» — это набор из пяти консольных игр, построенных по принципу популярных мобильных приложений для тренировки мозга. Каждая игра задает три вопроса, на которые нужно дать правильные ответы.

## Minimum Requirements
* PHP 8.1 или выше
* Composer

## Installation & Usage
1. Клонируйте репозиторий: `git clone https://github.com/mikhaelHan/php-project-45.git`
2. Перейдите в папку: `cd php-project-45`
3. Установите зависимости: `make install`
4. Запустите игру (пример): `make brain-even`
